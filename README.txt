دفتر صيانة السيارات - النسخة الأولى

طريقة التشغيل:
1) فك الضغط عن الملف ZIP.
2) افتح index.html بمتصفح Chrome أو Edge.
3) أضف السيارة ثم افتح "سجل الصيانة" لإضافة عمليات الصيانة.

ملاحظات:
- لا يحتاج إنترنت أو API.
- يحفظ البيانات محلياً في نفس المتصفح والجهاز.
- استعمل "النسخ الاحتياطي" لتصدير بياناتك إلى ملف JSON بانتظام.
- إذا مسحت بيانات المتصفح، قد تفقد البيانات المحلية ما لم تكن صدّرتها.
